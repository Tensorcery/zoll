# queries

Where a language holds code of another: one directory per host language,
`queries/<language>/injections.scm`, in tree-sitter's query language - the
same files editors use to highlight awk inside a shell string.

A file taken from Helix (`runtime/queries/<language>/injections.scm`) keeps
its MPL-2.0 header and stays a file of its own; a part that came from
nvim-treesitter keeps its Apache-2.0 attribution. Everything zoll writes
itself here is MIT, like the rest of the repository.
